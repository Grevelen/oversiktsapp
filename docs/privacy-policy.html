Personvernerklæring for Overs

Sist oppdatert: 8. november 2026

1. Kontakt

Spørsmål og forespørsler om personopplysninger kan sendes til sheikpruner@gmail.com.

2. Hvilke opplysninger som behandles

Overs kan behandle kontoinformasjon fra valgt innloggingsleverandør, som bruker-ID, navn og e-postadresse. Når brukeren aktiverer Min sky eller gruppesynkronisering, behandles økonomiopplysninger brukeren selv registrerer, blant annet inntekter, utgifter, sparing, forsikringer og abonnement. Overs behandler også gruppemedlemskap, gruppekoder og tekniske opplysninger som revisjonsnummer og tidspunkt for synkronisering.

3. Lokal lagring, Min sky og grupper

Data lagres lokalt på enheten som cache. Min sky er valgfri og knytter brukerens private Overs-data til kontoen, slik at data kan synkroniseres mellom enheter med samme konto. Gruppedata er tilgjengelige for medlemmer som aktivt blir med i gruppen. Gruppemedlemmer kan se og redigere gruppens delte økonomidata.

4. Formål og behandlingsgrunnlag

Opplysningene behandles for å levere funksjonene brukeren ber om, inkludert konto, sikkerhetskopiering, synkronisering, gruppedeling, medlemsadministrasjon og sletting. Valgfri skylagring og gruppedeling aktiveres av brukeren. Nødvendige sikkerhetsopplysninger kan behandles for å beskytte tjenesten og brukerne.

5. Databehandlere og lagringsregion

Overs bruker Supabase til autentisering, database og sanntidssynkronisering. Supabase-prosjektet er konfigurert i en europeisk region. Expo/EAS brukes til bygging og distribusjon av appen. Leverandørenes behandling reguleres av deres avtaler og personvernvilkår.

6. Gruppekoder

En gruppeeier kan opprette en tilfeldig åttesifret engangskode. Bare en hash av koden lagres. Koden utløper normalt etter 24 timer og blir ugyldig etter bruk. Innlogging og aktiv bekreftelse kreves før medlemskap opprettes.

7. Sikkerhet

Tilgang til private data og gruppedata styres med autentisering og Row Level Security. Private data kan bare leses av kontoeieren. Gruppedata kan bare leses av medlemmer av den aktuelle gruppen. Klientappen inneholder ikke Supabase service-role-nøkkel eller Apple private nøkkel.

8. Lagring og sletting

Data lagres til brukeren sletter dem, sletter gruppen eller sletter kontoen. Kontosletting kan startes i appen. Dersom brukeren eier en gruppe med andre medlemmer, må medlemskap først fjernes eller eierskapet håndteres før kontoen kan slettes. Sletting av konto fjerner private skydata, profil og medlemskap. Lokale data på andre enheter kan kreve at appdata slettes fra selve enheten.

9. Deling

Overs selger ikke personopplysninger. Gruppedata deles bare med brukere som har blitt medlemmer av gruppen. Opplysninger kan ellers utleveres dersom dette er lovpålagt.

10. Rettigheter

Brukeren kan be om innsyn, retting, sletting, begrensning, dataportabilitet og protest der dette følger av personvernregelverket. Data kan eksporteres fra appen. Klage kan sendes til Datatilsynet.

11. Endringer

Denne erklæringen oppdateres når funksjonalitet, leverandører eller databehandling endres. Gjeldende versjon publiseres på Overs-nettstedet og er tilgjengelig fra appen.
